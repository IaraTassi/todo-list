# 📋 Task Manager

Bem-vindo ao repositório das atividades da disciplina **Desenvolvimento de Aplicações Orientadas a Componentes**.

Este projeto foi criado para reunir as implementações desenvolvidas ao longo da disciplina, organizadas em branches específicas para cada tarefa proposta.

## 🚀 Primeira Tarefa

Utilizando React, a proposta desta atividade consiste no desenvolvimento de uma aplicação de teste. Como solução, foi implementada uma aplicação simples para gerenciamento de tarefas, explorando conceitos de componentização e estilização com CSS.

## 🚀 Segunda Tarefa

Aplicação desenvolvida em React para gerenciamento de tarefas, permitindo criar, organizar e acompanhar atividades de forma simples e intuitiva utilizando componentes.

- Funcionalidades
- Adicionar novas tarefas
- Remover tarefas
- Marcar tarefas como concluídas
- Filtrar tarefas por prioridade
- Interface responsiva para dispositivos móveis
- Feedback visual para tarefas concluídas

### Tecnologias Utilizadas

- React
- JavaScript
- CSS
- Vite

## 🌿 Organização das Branches

- `feature/task-primary` — Implementação da primeira tarefa.
- `feature/task-secondary` — Implementação da segunda tarefa.
